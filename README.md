# Bayt Prime Ventures Ltd — website

One-page business profile for Bayt Prime Ventures Ltd (RC 9181664): import and export, procurement, construction, general trading and logistics in Nigeria.

Plain HTML, CSS and JavaScript with no build step and no dependencies. Open `index.html` in a browser, or upload the folder to any static host (GitHub Pages, Netlify, cPanel).

## Files

| Path | Contents |
| --- | --- |
| `index.html` | The page and all its content |
| `css/style.css` | Styles (navy, gold and cream from the logo) |
| `js/main.js` | Mobile menu, hero slideshow, section highlights, enquiry form |
| `images/` | Logo, favicon, share image and WebP photos |

## Before going live

- Replace `images/og-image.jpg` in the `og:image` tag with the full `https://` address once the domain is known.
- The Projects section is in `index.html` but hidden. Remove its `hidden` attribute and add the link to both menus once real projects are ready.
- The enquiry form opens WhatsApp (+234 913 500 1107) with the message filled in.
